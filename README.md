# Senior Services Sales & Services Data Model

This repository contains mock data and an analytics-ready data model built for a fictional Senior Services sales company. The goal is to demonstrate analytics engineering concepts using dbt, PostgreSQL, and real-world-style datasets.

---

## 📁 Project Contents

| File | Description |
|------|-------------|
| `Data Table Master.xlsx` | Source Excel file containing mock tables for leads, appointments, conversions, reps, and services |
| `mock_leads.csv` | Generated mock leads dataset |
| `mock_appointments.csv` | Generated mock appointments dataset |
| `mock_conversions.csv` | Generated mock conversions dataset |
| `mock_reps.csv` | Mock sales reps information |
| `mock_services.csv` | Available services data |

---

## 🧠 Use Case

This project simulates a scenario where a home healthcare company:
- Tracks incoming leads from various sources
- Schedules and completes appointments
- Converts leads to clients via services
- Assigns reps to territories
- Analyzes service and conversion performance

---

## 🛠️ Tools & Technologies

- `Excel` — for initial data planning and generation
- `dbt` — for data modeling and transformation
- `PostgreSQL` — as the data warehouse
- `GitHub` — version control and project portfolio

---

## 📈 Goals

- Create a clean and logical data model for sales & service tracking
- Build reusable dbt models
- Enable reporting on KPIs like:
  - Lead-to-conversion rates
  - Appointment success rates
  - Service type distribution
  - Rep performance by territory
